# Processed data: catalogue and shared feature matrix (version 2)

Generated by `scripts/build_features.py` from the Kaggle files in `data/raw/` (not committed).
To regenerate: `python scripts/build_features.py` (add `--extras` for `features.csv` and the raw sparse blocks).

## Files
- `catalogue.csv`: 9,025 movies + train/held-out split (8,171 / 854, seed 2026). Everyone uses this catalogue and this split.
- `movies_clean.csv`: one readable row per movie with all covariates (lists joined by `|`), same order as the catalogue.
- `features.npz`: the numeric matrix, 9,025 x 902 (see below).
- `builder.joblib`: the fitted builder, places new movies in the same space.
- `blocks.json`: columns, encoding and weight of each block. `report.txt`: coverage. `dropped_films.csv`: 41 movies without metadata.
- `preference_lists_top10.csv`: users' top-10 lists (from `preference_dataset/`).

## How to load
```python
import numpy as np, pandas as pd
z = np.load("data/processed/features.npz")
X, movie_ids, columns = z["X"], z["movieId"], z["columns"]
cat = pd.read_csv("data/processed/catalogue.csv")   # same row order as X
train = (cat["split"] == "train").to_numpy()
```
Fit your method on `X[train]` only, then place every movie. Evaluate with
`scripts/evaluate_embedding.py` (see its docstring).

## The columns
One row per movie, built only from movie metadata (ratings are never used to build it).

| block | columns | how | weight |
|---|---|---|---|
| text (overview + tagline) | 0-99 | TF-IDF, compressed with SVD to 100 | 0.5 |
| genres | 100-119 | one 0/1 column per genre (20) | 1.5 |
| language | 120-130 | 10 most frequent + "other" | 0.25 |
| keywords | 131-258 | random code, 128 | 1 |
| cast (top 5 actors) | 259-386 | random code, 128 | 1 |
| directors | 387-514 | random code, 128 | 1 |
| writers (whole Writing department) | 515-642 | random code, 128 | 1 |
| production companies | 643-770 | random code, 128 | 1 |
| saga | 771-898 | random code, 128 | 1 |
| year, log runtime, log budget | 899-901 | standardized numbers | 1.5 |

Left out on purpose: popularity, vote_average, vote_count, revenue (they measure success, which the
Plackett-Luce model has to estimate).

**Random codes.** Every name (an actor, a director, a saga...) gets a fixed random vector of 128 numbers,
generated from the name itself. A movie's block is the sum of the codes of its names, rescaled to length 1.
Two movies with the same director have the same director block (distance 0); two different directors are
almost perpendicular (distance about 1.41 for every pair). A single column means nothing; only the whole
block does. Names seen in one movie only, and empty lists, get a code of their own, so they are neutral:
no "cluster of movies with missing metadata". New names work for new movies. Cost: a little noise (two
unrelated codes look about +-9% similar). With SVD (version 1) only the most frequent names survived (the
~30 most prolific directors, actors like Tom Hanks) and their movies dominated the distances.

**Budget.** Missing for about half of the movies. It is filled by a ridge regression on year, runtime,
genres, language and production companies, fitted on training movies with a known budget (R^2 in
`report.txt`). Version 1 used the median plus a 0/1 "budget missing" column, which split the map in two
halves (budget known / unknown in TMDb).

**Weights.** Each block is first rescaled to total variance 1 (so a block with many columns does not
dominate), then multiplied by its weight; its contribution to squared distances grows with the weight
squared. The weights were chosen with a grid search: 108 combinations, chosen on half of the users with
the time-matched taste test, confirmed on the other half.

## How we checked it
With an ablation study (each block alone, the matrix without each block, both encodings) and the weight
search; the analysis scripts will be added with the report. Taste AUC on the full matrix (0.5 = no
signal), version 1 -> version 2:

| taste test | v1 | v2 |
|---|---|---|
| random pairs | 0.525 | 0.585 |
| random pairs from users active at the same time | 0.521 | 0.572 |
| a user's top-10 vs movies the same user disliked | 0.481 | 0.561 |

Genres and runtime/budget carry most of the taste signal; the name blocks add little on average but give
sensible neighbours (Pulp Fiction -> Kill Bill, Reservoir Dogs, Jackie Brown; Toy Story -> its sequels,
A Bug's Life, Monsters, Inc.).

## Known limits
- Year: most of its apparent taste signal comes from *when* users were active (someone active in 1997
  cannot have 2010 movies in the list); it does not separate liked from disliked movies.
- On a 2D UMAP map the documentaries form their own island, and a few small groups (animated shorts,
  Dragon Ball) are separate; the rest is one continent organised by genre.
